# 🎓 StudentHub Portal

## 📌 Project Overview

StudentHub is a centralized student management portal designed to provide students with easy access to academic and campus-related information from a single platform.

The portal helps students manage their courses, assignments, study materials, attendance, timetable, notices, events, and feedback in an organized way.

---

## 🎯 Problem Statement

Students often need to use different platforms to access academic information such as notices, assignments, study materials, attendance, and events.

StudentHub aims to provide a single centralized platform where students can access all important academic and campus-related information easily.

---

## 🚀 Project Objectives

- Provide a centralized student portal
- Display important academic information
- Manage courses and assignments
- Provide access to study materials
- Display attendance information
- Show timetable and upcoming events
- Display important notices
- Provide a structured and user-friendly interface

---

## 👥 User Roles

### 👨‍🎓 Student

Students can:

- View their dashboard
- View and manage their profile
- View courses
- Check assignments
- Access study materials
- Check attendance
- View timetable
- View notices
- View upcoming events
- Submit feedback

### 👨‍💼 Admin

Admin can:

- Manage students
- Manage courses
- Manage assignments
- Manage events
- Manage notices
- Monitor portal activities

---

## 📄 Main Pages

The StudentHub portal contains the following pages:
